## 1. Sitemap → Indexability Relationship
The authoritative relationship has been strictly enforced and validated programmatically:
- `eligible` -> `index, follow` + canonical + in sitemap.
- `not-yet-eligible` -> `noindex, nofollow` + canonical + NOT in sitemap.
- `noindex` -> `noindex, nofollow` + NOT in sitemap.
